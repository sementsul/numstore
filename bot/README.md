# MagzGold — чат-бот оформления (PHP, без крона/SSL)

Бот-файл лежит на Бегете как обычный PHP по HTTP-адресу. Крона нет → «будит» его внешний бесплатный
пингер (cron-job.org) раз в минуту. За заход бот быстро забирает новые сообщения из Телеграма и отвечает.
SSL не нужен: пингер ходит по http, а бот к Телеграму — исходящим https (работает всегда).

## Что залить на Бегет (по FTP)
Папка `bot/` → на Бегет, например в `~/magzbot/` (лучше ВНЕ веб-корня публичных файлов, но так, чтобы
`bot.php` открывался по http). Файлы:
- `bot.php` — сам бот
- `config.php` — создать из `config.sample.php`, вписать токен и ключ (НЕ коммитить)

Права на запись в папку нужны (бот пишет `offset.txt` и `bot.lock`).

## Настройка config.php
```php
<?php
return [
  'token'  => '8698164422:AAG...',        // токен бота от @BotFather
  'ref_id' => '800848',                    // реф-id партнёра
  'key'    => 'любая_случайная_строка',    // защита URL
];
```

## Внешний пингер (вместо крона)
1. Узнай http-адрес файла на Бегете, напр. `http://ТВОЙ-домен.beget.tech/magzbot/bot.php`
2. Проверь в браузере: `http://.../magzbot/bot.php?key=твой_ключ` → должно вывести `ok`.
3. Заведи бесплатный пингер **cron-job.org**:
   - New cronjob → URL: `http://.../magzbot/bot.php?key=твой_ключ`
   - Интервал: каждую **1 минуту**.
   - Сохрани. Всё — бот отвечает с задержкой до ~1 мин.

(Альтернатива пингеру — GitHub Actions, но там минимум 5 мин и тратятся приватные минуты. cron-job.org лучше.)

## Проверка
Напиши боту `/start` → выбери категорию → номер → «Забронировать». Бот забронирует и даст ссылку на
завершение у оператора (паспорт РФ + оплата — на стороне Безлимита).

## Заметки
- Токен только в `config.php` (в `.gitignore`). PHP не отдаёт исходник по http — файл исполняется.
- Один пингер на бота. НЕ запускать бота ещё и long-polling в другом месте одновременно (Telegram даёт 409).
- Меню-кнопка бота ведёт на мини-апп (каталог) — это отдельно и уже работает.

## Подписки на маски номеров (watch)
Новое: пользователь подписывается на маску номера и получает уведомление, когда такой номер появится.
- Команды бота: `/watch NNNNNNN7777` (N — любая цифра), `/mywatches` — список/отписка.
- С сайта: кнопка «🔔 Следить» у маска-поиска (/start/, категории) → deep-link `t.me/magzgoldbot?start=watch_<маска>`.
- Хранилище: `watches.json` (рядом с bot.php, нужны права на запись — как offset.txt).
- Проверка: `check_watches()` вызывается раз за поллинг-цикл, троттлинг 30 мин (файл `watch_check.txt`).
  По каждой уникальной маске — mask-поиск в API Безлимита, новые номера → уведомление, дедуп по номерам.
- **ДЕПЛОЙ:** перезалить `bot.php` на Бегет (по FTP), убедиться что папка пишет `watches.json`/`watch_check.txt`.
