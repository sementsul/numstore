# Живые юзер-кейсы — numstore (реферальная витрина номеров Безлимит)

Формат: предусловие → шаги → ожидаемый результат + РАДИУС + статус ✅/❌ (❌ = ещё не подтверждён ручным тестом).

## Радиус проекта (что затронуто + соседи/роли)
- **Файлы:** `index.html` (разметка/контролы), `app.js` (fetch каталога + рендер + фильтры), `config.js`
  (API_BASE, публичный токен, реф-URL), `styles.css`.
- **Внешняя зависимость:** API Безлимит `api.store.bezlimit.ru/v2` (недокументированный, CORS открыт).
- **Роли:** посетитель (смотрит/фильтрует/жмёт «купить»); партнёр-владелец (получает реф-комиссию 800848).
- **Соседнее:** реф-поток Безлимит (`l.bezlimit.ru/store/800848`) — атрибуция покупки (пока через редирект).

## UC-1. Загрузка каталога (клиент, ban-proof) ❌
**Предусловие:** сайт открыт в браузере посетителя (его IP, не CI). **Шаги:** открыть `/`.
**Ожидаемо:** `app.js` делает `GET /super-link/phones/collection?expand=phones.tariff` с Basic-токеном,
сплющивает `items[].phones[]`, вместо «Загружаю номера…» рендерит карточки. **Проверка:** ручной тест в браузере.

## UC-2. Карточка номера ❌
**Предусловие:** каталог загружен. **Шаги:** посмотреть карточку.
**Ожидаемо:** номер как `+7 958 494-94-94`, название тарифа, `минуты·смс·ГБ`, цена тарифа `/мес`.
🔺 ДОПУЩЕНИЕ: показываем цену ТАРИФА, не цену номера (поле цены номера ещё не определено).

## UC-3. Поиск по номеру ❌
**Предусловие:** каталог загружен. **Шаги:** ввести цифры в поиск.
**Ожидаемо:** список фильтруется по вхождению цифр в `phone` (нецифры игнорируются).

## UC-4. Фильтр по тарифу ❌
**Шаги:** выбрать тариф в селекте. **Ожидаемо:** остаются номера только этого тарифа; опции собраны из каталога.

## UC-5. Сортировка по цене тарифа ❌
**Шаги:** выбрать «Цена тарифа ↑/↓». **Ожидаемо:** порядок по `tariff.price` возр./убыв.

## UC-6. Кнопка «Купить» → реф ❌
**Шаги:** нажать «Купить». **Ожидаемо:** новая вкладка `l.bezlimit.ru/store/800848` (несёт реф-id 800848).
🔴 ОТКРЫТО: точная атрибуция покупки к 800848 (эндпоинт брони/оплаты) — снять из Network, подтвердить деньгами.

## UC-7. Ошибка загрузки ❌
**Предусловие:** API недоступен/сменил токен. **Шаги:** открыть `/`.
**Ожидаемо:** статус «Не удалось загрузить номера (HTTP …). Обнови страницу», не белый экран.

## UC-8. Поиск по маске (cubes) — живая подгрузка из API ❌
**Предусловие:** каталог показан. **Шаги:** заполнить ячейки маски (10 позиций): цифра — точная,
пусто → `N` (любая), буква `a/b/c…` — повторяющаяся цифра. **Ожидаемо:** с дебаунсом 500мс летит
`GET /super-link/phones/mask-category?expand=tariff&is_reserved=false&per_page=60&phone_pattern=<маска>`;
ответ — объект-группы `{"<категория>":{items:[номера]}}`, `extractPhones` вытаскивает номера из любой
структуры; показываются все подходящие (не только стартовые коллекции). Пустая маска → дефолтные коллекции.
✅ ПОДТВЕРЖДЕНО: параметр API = **`phone_pattern`** (НЕ `cubes` — тот API игнорирует), `N` = любая цифра,
10 позиций. Проверено: `9NNNNNNNNN`→все на 9 (250 шт.), `99NNNNNNNN`→все на 99 (211 шт.).
NB: в реф-ссылку на сайт Безлимит маска идёт как `cubes`, а в API-поиск — как `phone_pattern`.

## UC-9. Генерация реф-ссылки на выборку ❌
**Шаги:** заполнить маску. **Ожидаемо:** появляется блок с готовой ссылкой
`https://l.bezlimit.ru/store/800848?type=p&cubes=<маска>`, кнопки «Копировать» и «Открыть в магазине».
Кнопка «Купить» на карточке ведёт на КОНКРЕТНЫЙ номер: `?type=p&cubes=<весь номер>&uuid=<uuid листинга>`
(uuid берём из объекта номера, если есть; иначе только cubes=<номер>). Реф 800848 в домене store.
«Открыть в магазине» из блока маски ведёт на выборку `?type=p&cubes=<маска>`.
Формат брони подтверждён: `store/800848?type=p&cubes=9348882888&uuid=…`.
